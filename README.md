# Sywnex-Task-2-EDA-
Sywnex Internship Task 2 – Exploratory Data Analysis using Microsoft Excel. This project includes data analysis, Pivot Tables, statistical calculations, charts, trend and pattern identification, anomaly analysis, and five key insights derived from the cleaned dataset.
Sywnex Internship – Task 2

Exploratory Data Analysis

📌 Project Overview

This project is part of my Sywnex Technology Internship – Task 2. The objective was to perform Exploratory Data Analysis (EDA) on the cleaned dataset from Task 1 using Microsoft Excel.

🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Charts & Data Visualization
- Statistical Analysis

📊 Analysis Performed

- Calculated important statistical measures such as Average, Median, and Standard Deviation.
- Created Pivot Tables for department and city-wise analysis.
- Created charts to visualize data and identify patterns.
- Analysed trends and variations in salary and employee distribution.
- Checked the dataset for unusual values and anomalies.

🔍 Key Insights

1. HR recorded the highest number of employees with 115 records, while Marketing had the lowest with 89 records.
2. HR had the highest total salary expenditure, approximately 10.87M.
3. Islamabad had the highest employee count with 106 employees, followed by Peshawar with 104.
4. The average salary was 92,154.12, while the median salary was 94,056.68.
5. The standard deviation was 26,659.21, showing noticeable variation in salary values.
6. No significant anomalies were identified during the analysis.
